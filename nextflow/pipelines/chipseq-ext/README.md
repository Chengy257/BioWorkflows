# chipseq-ext - local extension stages for the adopted nf-core/chipseq route

Consumes the published results of an adopted nf-core/chipseq run (dev HEAD
`1b3078d71c4c8126a9b976d3b0248e9b9b525608`) and adds the ratified local
capabilities (scientific decision record:
`nextflow/docs/chipseq-scientific-decision-record.md`). Every stage is
default-off; enable stages per project with `-params-file` or `--` params.

## Stages

| Stage (param gate) | Capability | Ecosystem module usage |
|---|---|---|
| `organelle_qc.enabled` | Chloroplast/mitochondrial read fraction per sample (rice-critical; no native equivalent) | `samtools/idxstats` |
| `qc_gates.enabled` | PASS/WARN/FAIL gate table from flagstat mapping rate, picard duplication, organelle fraction | - |
| `spike_in.enabled` | Spike-in scale factors from a combined-reference run + optional per-sample bigWig rescaling | `samtools/idxstats`; local `bamCoverage` wrapper (per-sample runtime scale factor) |
| `idr.enabled` | ENCODE-style pairwise IDR on the native per-sample narrowPeak calls, union by replicate support | `idr` |
| `seacr.enabled` | Pooled per-group SEACR peak calling for CUT&Tag/CUT&RUN samples (alternative caller) | `samtools/merge`, `deeptools/bamcoverage`, `seacr/callpeak` |
| `homer_motif.enabled` | HOMER findMotifsGenome.pl on the native consensus peaks (no ecosystem module exists) | - |
| `diffbind.enabled` | DiffBind differential binding (DESeq2/edgeR, summit-window counting, batch blocking) - ecosystem vacuum | - |

## Consumed adopted-run contract

`ext_results_dir` points at the adopted run's `--outdir`. Expected layout
(dev HEAD, default publish paths; every directory/suffix is overridable via
`ext_*` params):

```
{ext_results_dir}/{ext_aligner}/filtered_bam/{sample}.mLb.clN.sorted.bam(+.bai)
{ext_results_dir}/{ext_aligner}/merged_library/macs3/{ext_peak_type}/{sample}_peaks.narrowPeak
{ext_results_dir}/{ext_aligner}/merged_library/macs3/{ext_peak_type}/consensus/{antibody}/{antibody}.consensus_peaks.bed
{ext_results_dir}/{ext_aligner}/bigwig/{sample}.mLb.clN.bigWig
{ext_results_dir}/{ext_aligner}/flagstat/{sample}.mLb.clN.sorted.flagstat
{ext_results_dir}/{ext_aligner}/duplicateMarked/{sample}.duplicate_metrics   (optional, ext_dup_glob)
```

The sample sheet (`ext_sample_sheet`) is a CSV with header
`sample_id,group,condition,control,batch`: one row per sample, `control`
naming the group's control sample (empty when none; the control may live in
its own group), `condition` used by DiffBind contrasts, `batch` optional
blocking factor. Sample ids must not contain `_vs_` (used by the IDR pair
slug).

## Usage

```bash
# Dry-run baselines (fixtures regenerated by tests/make_fixtures.sh):
nextflow run . -profile test -preview        # all stages off: 0 tasks
nextflow run . -profile test_full -preview   # all stages on

# Real run against an adopted run's results:
nextflow run . -profile apptainer \
    -c ~/.nextflow/config \
    --ext_results_dir /path/to/adopted/results \
    --ext_sample_sheet /path/to/samplesheet.csv \
    --params-file my-ext-params.yaml
```

## Containers

Per-step modular containers (design doc D6): ecosystem modules carry their
own images; local processes declare `quay.io/biocontainers/...` tags verified
against the registry on 2026-10-06 (`python:3.12.12`,
`bioconductor-diffbind:3.20.0--r45ha27e39d_0`, `homer:5.1--pl5321hc52dbad_1`,
and the samtools+deeptools mulled image reused from the ecosystem module).
Images are seeded via the validated acquisition recipe (implementation
guidance Section 3.1); unreachable sources are rewritten in the machine-local
container-override configuration.
